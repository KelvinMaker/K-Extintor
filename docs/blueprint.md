# **App Name**: FireSafe

## Core Features:

- Expiry Date Input: Input the expiry date for the fire extinguisher.
- Clear Compliance Overview: See a clear display of when the fire extinguisher needs to be replaced, and if it is compliant with safety regulations.
- Renewal Alerts: Allow alerts for renewal, 3 months before renewal.
- Smart Extinguisher Information Reader: AI tool: automatically fill information, from photo (date of manufacture, type of extinguisher)

## Style Guidelines:

- Primary color: Deep red (#C70039), evoking a sense of safety and urgency.
- Background color: Soft off-white (#F2E8E5) to provide a clean and accessible visual backdrop.
- Accent color: Burnt orange (#E57A44) for calls to action and important notifications, creating a clear visual hierarchy.
- Use clear, sans-serif fonts to display dates.
- Simple icons to represent the compliance status of extinguishers.
- Clean and structured layout with a clear visual hierarchy for easy navigation and quick access to essential information.
- Use subtle transitions when changing dates.
